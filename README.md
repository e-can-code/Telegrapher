# Telegrapher Web 2.5.1

Extract this archive and serve index.html at the web root. GitHub Pages subdirectories are supported. On desktop widths 850px and above, the correspondence desk shows a docked Notes pane in Listen, a collapsible Compose message, and compact top navigation. F and J insert dit and dah into Notes when the keyboard is not focused in a text field. Settings allows reassignment. Android application source is not included or modified.
